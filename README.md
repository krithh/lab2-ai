# Лабораторная работа №2

## Задачи регрессии и классификации

В работе используется обработанный датасет Titanic, подготовленный в лабораторной работе №1.

## Цель работы

Изучить задачи регрессии и классификации, обучить линейную и логистическую регрессии, а также оценить качество полученных моделей.

## Выполненные действия

- датасет разделён на обучающую и тестовую выборки;
- для разделения использовалось 80% данных для обучения и 20% для тестирования;
- решена задача регрессии для признака `Fare`;
- регрессионная модель оценена с помощью MAE, MSE, RMSE и R²;
- решена задача классификации для признака `Survived`;
- классификационная модель оценена с помощью Accuracy, Precision, Recall и F1-score;
- построена матрица ошибок.

## Результаты регрессии

Для прогнозирования нормализованной стоимости билета использовалась линейная регрессия.

- MAE: 0.0368
- MSE: 0.0036
- RMSE: 0.0604
- R²: 0.3822

Модель объясняет около 38,22% изменений стоимости билета. Она лучше предсказывает небольшую стоимость и занижает стоимость дорогих билетов.

## Результаты классификации

Для прогнозирования выживания пассажиров использовалась логистическая регрессия.

- Accuracy: 0.7933
- Precision: 0.7759
- Recall: 0.6522
- F1-score: 0.7087

Модель правильно классифицировала 142 из 179 пассажиров тестовой выборки.
